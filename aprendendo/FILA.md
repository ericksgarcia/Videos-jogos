# Fila de vídeos (pedido do dono)

Regra: **um vídeo de cada vez** — roteiro → narração → cenas → prévia → render → entrega.
Antes de começar cada um, confira em `aprendendo/videos/` se o tema já foi feito.
Ao terminar, mova o item para "Feitos" (com a pasta) e passe para o próximo.
